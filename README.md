## 🛠️ Technology Stack & Architecture

- **Frontend Core:** React 19 + Vite 8
- **Styling System:** Tailwind CSS v4 + Dark-Luxe Obsidian Palette
- **Typography:** Syne (Display), Plus Jakarta Sans (Headings), Inter (Body), JetBrains Mono (Technical/Metrics)
- **Interactive Features:** Real-time growth metric simulators, case study modal inspection, direct contact clipboard & WhatsApp triggers, celebratory confetti triggers.
- **Search Engine Optimization (Technical SEO):**
  - Semantic HTML5 document outline (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, strict `<h1>`-`<h4>` hierarchy)
  - Schema.org Structured Data (`Person`, `WebSite`, `BreadcrumbList`, and `CreativeWork` JSON-LD)
  - Full OpenGraph & Twitter/X card metadata
  - Standalone `sitemap.xml` and `robots.txt`
  - Zero layout shift (CLS: 0.00) and instant First Contentful Paint.

## ⚡ Local Development

To run the project locally:

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build production bundle
npm run build

# 4. Preview production build locally
npm run preview
```

## 🌐 Deployment to Vercel

This repository is pre-configured and 100% ready for instant 1-click deployment on **Vercel**:

1. Push your repository to GitHub:
   ```bash
   git add .
   git commit -m "feat: complete premium portfolio website for Manya Garg"
   git branch -M main
   git remote add origin <your-github-repo-url>
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and log in.
3. Click **"Add New Project"** -> Select your GitHub repository.
4. Framework Preset will automatically detect **Vite**.
5. Click **"Deploy"**.
